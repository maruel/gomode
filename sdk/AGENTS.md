# SDKs

Generated API SDKs for Go Mode discovery, MCP, OAuth, and voice gateway live
here alongside the Halo Android SDK. Edit the owning Go DTO and route spec,
then run `make generate-sdks`; do not edit generated clients directly.

Keep each protocol's TypeScript, Kotlin, Swift, and API reference outputs
together. `halo/AGENTS.md` governs the handwritten Halo SDK.
